# Notes on Terminal Design

Terminal interfaces reward restraint.

Every extra decoration has to justify itself because there is so little room to hide unnecessary structure. That turns spacing, hierarchy, and motion into stronger tools than sheer density.

## Useful constraints

1. Keep the navigation model obvious.
2. Make the primary content readable at narrow widths.
3. Use styling to separate meaning, not to add noise.

Code blocks, lists, and headings matter more here because they create landmarks in a format that can otherwise blur together.
